# 🌾 AgroSense

**AI-powered smart farming platform built for Indian farmers.**

AgroSense combines crop disease detection, hyperlocal weather, live Mandi prices, and voice-based advisory — in Hindi and English — into a single mobile-friendly web app.

## Features

### 🔬 AI Crop Disease Scanner
Upload a photo of any crop or leaf. Groq's Llama 4 Scout Vision model identifies the disease, severity, confidence score, and gives step-by-step treatment instructions.

### 🌦️ Hyperlocal Weather
GPS-based current weather and 5-day forecast via OpenWeatherMap. Heatwave and heavy rain alerts fire automatically based on live conditions.

### 💧 Smart Irrigation
Weather-based soil moisture estimate with irrigation timing recommendations. Updates with every weather refresh.

### 🌱 AI Crop Advisory
Per-crop advisory covering irrigation, fertilizer, and pest risk — generated by Groq AI using your GPS location and live weather. Available for 80+ crops.

### 📊 Live Mandi Prices
Real-time commodity prices from the Government of India's data.gov.in API. Covers Wheat, Onion, Tomato, Maize, Rice, Potato, Soybean, and Cotton.

### 🎙️ Voice Assistant
Speak your question in Hindi or English — the app transcribes it, sends it to the AI, and reads the answer back using the Web Speech API.

### 🔔 Smart Alerts
Weather, disease risk, market, and irrigation alerts — filtered by your notification preferences saved to your profile.

## Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn
- Accounts for: Google Cloud, Supabase, Groq, OpenWeatherMap, data.gov.in (all free)

### 1. Clone and install
```bash
git clone https://github.com/your-username/AgroSense.git
cd AgroSense
npm install
```

### 2. Set up environment variables
```bash
cp .env.example .env.local
```
Fill in your keys — see `.env.example` for where to get each one.

### 3. Set up Supabase tables

Run this SQL in your Supabase project's SQL editor:

```sql
-- Profiles
create table profiles (
  email text primary key,
  name text,
  avatar_url text,
  farm_name text default 'My Farm',
  land_size text default '5',
  state text default 'Maharashtra',
  district text,
  soil_type text,
  soil_types jsonb default '[]',
  crops jsonb default '[]',
  language text default 'en',
  notifications jsonb default '{"weather":true,"disease":true,"market":true,"irrigation":true}',
  created_at timestamptz default now(),
  updated_at timestamptz default now()
);

-- Disease scans
create table disease_scans (
  id uuid primary key default gen_random_uuid(),
  user_email text references profiles(email) on delete cascade,
  crop_name text,
  disease text,
  confidence int,
  severity text,
  health_score int,
  treatment jsonb,
  nutrients jsonb,
  summary text,
  created_at timestamptz default now()
);

-- Farm alerts
create table farm_alerts (
  id uuid primary key default gen_random_uuid(),
  user_email text references profiles(email) on delete cascade,
  type text,
  icon text,
  title text,
  description text,
  is_read boolean default false,
  created_at timestamptz default now()
);
```

### 4. Run
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000).

## Known Limitations

- **Market price trends** are illustrative — based on today's live price. Real historical data would require a separate data pipeline.
- **Irrigation recommendations** are weather-based estimates, not sensor readings.
- **Voice advisory** requires an active internet connection — it uses live AI calls, not an offline model.
- **Language support** is currently English and Hindi. More languages are planned.
